# MIDI Digital Synthesizer and Audio Effects Prototype

Python code converts MIDI note information into synthesized waveforms with an envelope and explores an audio-effects rack. This source-derived report documents the oscillator/effect algorithms and identifies timing, state, and numerical issues that limit fidelity. A separate submitted narrative report was not present.

## Technical highlights

- Developed a Python MIDI-to-audio synthesis prototype with note-frequency mapping, envelope shaping, and modular audio effects.
- Explored delay, modulation, compression, saturation, reverberation, and time-frequency processing; reviewed signal-state and timing correctness.
